資料前處理：從 train.csv 到 clean_train.csv

原始資料雖然包含完整的農業環境資訊，但其中有文字類別欄位、 不同尺度的數值欄位，以及不適合訓練的 id 欄位，因此需要先進行資料前處理。

原始資料概況

項目 內容
資料檔案 train.csv
資料筆數 630,000 筆
原始欄位數 21 欄
目標欄位 Irrigation_Need
分類結果 Low / Medium / High

為什麼需要資料前處理？

機器學習模型主要處理數值資料，但原始資料中包含 Soil_Type、Crop_Type、Season、Region 等文字類別欄位， 因此需要將文字轉換為數字。此外，像 Soil_pH 與 Rainfall_mm 的數值範圍差異較大，也需要透過標準化降低尺度差異對模型訓練的影響。

clean_train.csv 產生流程

1. 讀取原始 train.csv
2. 刪除無預測意義的 id 欄位
3. 將 Mulching_Used 轉為 0 / 1
4. 將 Irrigation_Need 轉為 Low = 0、Medium = 1、High = 2
5. 對 Soil_Type、Crop_Type、Season、Region 等欄位進行 One-Hot Encoding
6. 對數值欄位進行 Standard Scaling
7. 輸出整理後的 clean_train.csv

Label Encoding

將目標欄位 Irrigation_Need 從 Low、Medium、High 轉換成 0、1、2，讓模型能夠進行分類訓練。

One-Hot Encoding

將沒有大小順序的類別欄位展開成 0 / 1 欄位， 避免模型誤判類別之間存在大小關係。

Standard Scaling

將數值欄位標準化，使不同尺度的特徵能在較一致的範圍內參與模型訓練。

Remove ID

id 僅代表資料編號，沒有實際農業意義，因此在模型訓練前刪除。
