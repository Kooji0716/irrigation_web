非神經網路模型比較與特徵篩選測試

本頁整合第二位同學使用 Scikit-learn 與 XGBoost 訓練的非神經網路模型結果， 並加入 Accuracy、Precision、Recall 與 Balanced Accuracy 作為模型評估指標。

模型訓練說明

本部分使用清理後的 clean_train.csv 作為訓練資料， 並將資料切分為 60% 訓練集與 40% 測試集。 使用的模型包含 Logistic Regression、Random Forest、XGBoost 與 HistGradientBoostingClassifier。原先也嘗試加入 SVM， 但由於資料量過大，訓練時間過長，因此最後未納入比較。

Logistic Regression

線性分類基準模型，用來觀察較簡單模型在本資料集上的表現。

Random Forest

由多棵決策樹組成，能處理非線性關係，也是本次特徵篩選後表現最佳的模型。

XGBoost

梯度提升樹模型，能逐步修正前一輪模型的錯誤，常用於表格資料競賽。

HistGradientBoosting

Scikit-learn 中的高效率梯度提升模型，適合處理大量表格資料。

特徵篩選測試

除了使用完整特徵進行訓練外，本研究也測試不同特徵篩選方式對模型表現的影響。 測試一為刪除與目標欄位相關性接近 0 的 Soil_pH 與 Sunlight_Hours； 測試二則是只保留前十個相關性較高的欄位進行訓練。

結果顯示，Logistic Regression 在刪除欄位或只保留前十欄位後表現皆略微下降； Random Forest 則在只保留前十個相關欄位後表現提升， 表示部分低影響力特徵可能會干擾 Random Forest 的分類判斷。 對 XGBoost 與 HistGradientBoostingClassifier 而言，刪除低相關欄位後表現並未提升， 因此後續未再進行測試二。

最終模型評估結果

由於本資料集存在類別不平衡問題，因此除了 Accuracy 之外， 本研究也加入 Balanced Accuracy 作為比較指標。 Balanced Accuracy 會平均觀察每個類別的辨識率，較能反映模型是否只偏向多數類別。

模型 最終版本 Accuracy Balanced Accuracy Precision Recall
Logistic Regression 完整特徵 0.8760 0.7751 0.8755 0.8760
Random Forest 前十相關欄位 0.9858 0.9611 0.9857 0.9858
XGBoost 完整特徵 0.9848 0.9610 0.9848 0.9848
HistGradientBoosting 完整特徵 0.9848 0.9607 0.9848 0.9848

整體模型比較圖

此圖比較四個模型的 Accuracy、Precision 與 Recall。 可以看出 Random Forest、XGBoost 與 HistGradientBoostingClassifier 的整體表現皆接近 0.985，明顯高於 Logistic Regression。

Balanced Accuracy 比較

Balanced Accuracy 是本次新增的重要評估指標。 從圖中可看出，Random Forest 在只保留前十相關欄位後， Balanced Accuracy 達到約 0.9611， 略高於 XGBoost 的 0.9610 與 HistGradientBoostingClassifier 的 0.9607。

Random Forest 特徵篩選前後比較

Random Forest 在使用完整特徵時已具有良好表現， 但經過測試二，也就是只保留前十個相關欄位後， Accuracy 與 Balanced Accuracy 皆進一步提升。 因此新版模型中另外儲存了 Rfmodelnew 作為更新後的 Random Forest 模型。

最終採用模型版本說明

由於每個模型在不同特徵篩選方式下的表現不同，因此本頁在混淆矩陣比較中， 並不是放入所有測試版本，而是選擇各模型最後採用或表現最佳的版本進行比較。

模型 最終採用版本 選擇原因
Logistic Regression 完整特徵版本 刪除低相關欄位與只保留前十欄位後，模型表現皆略微下降，因此保留完整特徵版本。
Random Forest 前十相關欄位版本 測試一刪除低相關欄位後表現提升，進一步測試只保留前十欄位後，Accuracy 與 Balanced Accuracy 皆達到最高。
XGBoost 完整特徵版本 刪除低相關欄位後 Balanced Accuracy 略微下降，因此未繼續進行測試二，並採用完整特徵版本。
HistGradientBoosting 完整特徵版本 刪除低相關欄位後模型表現未提升，因此未繼續進行測試二，並採用完整特徵版本。

結果小結

綜合比較結果可知，Logistic Regression 的表現明顯低於其他樹狀模型。 Random Forest、XGBoost 與 HistGradientBoostingClassifier 在 Accuracy 上皆達到約 0.985， 顯示樹狀模型能有效處理本資料集中土壤、氣候與作物條件之間的非線性關係。 其中 Random Forest 在只保留前十個相關欄位後，Accuracy 提升至約 0.9858， Balanced Accuracy 也提升至約 0.9611，成為本次非神經網路模型中表現最佳的版本。
