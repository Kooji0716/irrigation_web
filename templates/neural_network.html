Keras / TensorFlow 神經網路模型

本頁整合第三位同學使用 Keras / TensorFlow 建立的多分類神經網路模型結果。 模型以 clean_train.csv 作為資料來源，根據 42 個輸入特徵預測灌溉需求類別。

專案目標

本部分主要使用 Keras / TensorFlow 建立灌溉需求 Irrigation_Need 的多分類模型。分類目標共有三類： 0、1、2， 分別代表 Low、Medium、High 三種灌溉需求。

資料來源

使用清洗完成後的 clean_train.csv。

資料筆數

共 630,000 筆資料。

輸入特徵

共 42 個輸入特徵。

分類目標

Irrigation_Need：0 / 1 / 2。

模型架構

本次使用的是表格資料常見的多層感知器 MLP, Multi-Layer Perceptron。 模型由多層 Dense layer 組成，並加入 BatchNormalization、Dropout、 L2 Regularization 等方法，以提升訓練穩定性並降低過擬合風險。

Input：42 個特徵
↓
BatchNormalization
↓
Dense(128, ReLU)
↓
Dropout(0.30)
↓
Dense(64, ReLU)
↓
BatchNormalization + Dropout(0.20)
↓
Dense(32, ReLU)
↓
Dense(3, Softmax)

訓練技巧

BatchNormalization

讓每層輸入分布更穩定，使模型訓練過程更平順。

Dropout

訓練時隨機關閉部分神經元，降低模型過度記住訓練資料的風險。

L2 Regularization

限制權重過大，避免模型過度複雜化。

EarlyStopping

當驗證集表現不再進步時停止訓練，避免過擬合。

ReduceLROnPlateau

當驗證集 loss 停滯時降低 learning rate，使後期訓練更穩定。

class_weight

處理類別不平衡問題，讓模型更重視樣本數較少的類別。

資料切分方式

本次資料切分為訓練集、驗證集與測試集。訓練集用於模型學習， 驗證集用於訓練過程中觀察模型表現，測試集則用於最後評估模型效果。

資料集 筆數 用途
Train 455,175 模型實際學習資料
Validation 80,325 訓練過程中檢查模型表現
Test 94,500 最後評估模型表現

模型評估結果

神經網路模型在測試集上具有良好的分類表現。除了整體 Accuracy 外， 本研究也觀察 Balanced Accuracy，以確認模型在類別不平衡情況下是否仍能維持穩定辨識能力。

指標 結果 說明
Best Validation Accuracy 約 0.9775 訓練過程中驗證集達到的最佳準確率
Test Accuracy 約 0.9772 測試集整體預測正確率
Test Balanced Accuracy 約 0.9615 各類別召回率平均，較能反映類別不平衡下的表現

訓練過程：Loss 與 Accuracy

這張圖用來觀察模型是否正常收斂。左圖為 Loss，右圖為 Accuracy。 可以看到模型在訓練過程中逐漸穩定，且訓練集與驗證集表現沒有出現明顯過大落差。

類別分布

原始資料中 Low、Medium、High 三類樣本數差異明顯，其中 High 類別數量最少。 因此本次神經網路訓練加入 class_weight，讓模型在訓練時更重視少數類別。

結果小結

本次成功使用 Keras / TensorFlow 建立灌溉需求多分類神經網路模型。 模型在測試集上達到約 97.72% 的 Accuracy，以及約 96.15% 的 Balanced Accuracy。 這代表模型不只整體預測正確率高，在考慮類別不平衡的情況下，也具有良好的辨識能力。
